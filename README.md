## Proyectos destacados

### 🎬 Cinemapedia

Aplicación móvil desarrollada con Flutter para explorar, buscar y consultar
información sobre películas.

Incluye:

- Consumo de una API REST.
- Gestión de estado con Riverpod.
- Búsqueda y persistencia de consultas.
- Navegación entre pantallas.
- Carga progresiva de contenido.
- Diseño adaptable para dispositivos móviles.

**Tecnologías:** Flutter, Dart, Riverpod y The Movie Database API.

[![Repositorio](https://img.shields.io/badge/Ver_repositorio-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/SSJorge/cinemapedia)

---

### 📦 Plataforma de gestión de pedidos

Sistema full-stack para registrar, administrar y consultar pedidos desde
distintos dispositivos.

Incluye:

- Frontend desarrollado con React.
- API REST desarrollada con Go.
- Persistencia de datos con PostgreSQL.
- Autenticación de usuarios.
- Código público para consultar el estado de un pedido.
- Integración con un bot de Telegram.
- Despliegue del frontend en Vercel y del backend en Render.

**Tecnologías:** React, Go, PostgreSQL, Vite, Telegram Bot API, Vercel y Render.

[![Repositorio](https://img.shields.io/badge/Ver_repositorio-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/SSJorge/pedidos-react-go-postgres)
